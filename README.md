# MONOLIT — Design & Build

Concept website for an architecture, interiors and construction studio.

- `/` — version 2 (letter fly-through hero, WebGL image reveals, drawing-to-photo slider, mobile menu)
- `/v1/` — version 1

Stack: HTML/CSS/JS, GSAP + ScrollTrigger, Lenis, Three.js (WebGL shaders). No build step.

Live: https://bilanfreelance.github.io/monolit/
